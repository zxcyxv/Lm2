## Question and comparisons

What continuation quality has actually been learned after three epochs, and
where does it fail?  Re-evaluate the prior eight-sample qualitative claim on
64 fixed prompts.  Compare:

- H1 greedy with causal re-anchoring after every generated byte
- H1 temperature-0.8, top-p-0.9 sampling with causal re-anchoring
- H16 greedy with sixteen predicted bytes committed per block
- H16 temperature-0.8, top-p-0.9 sampling per block
- gold validation continuations and an all-space collapse baseline

All modes use the real final prefix position 255 as their anchor.  The H16
branch is a block generator, not an autoregressive-equivalent decoder.

- report aligned reference accuracy at lengths 1, 4, 8, 16, 32, 64, and 128
- report entropy, byte diversity, whitespace and printable fractions, UTF-8
  validity, repeated 4-grams, repeated word bigrams, identical-byte runs, and
  cross-prompt positional collapse
- report H16 statistics separately for each within-block phase 1 through 16
- report early/late position buckets for all modes

## Interpretation gates

- aligned accuracy after the first mismatch is not a semantic-quality metric;
  use it only to locate exposure-bias decay
- a high all-space accuracy is a baseline, not language quality
- do not generalize greedy mode collapse to the full learned distribution
  unless fixed top-p samples also collapse
- do not call diverse output coherent unless the recorded samples have local
  syntax and prompt-conditioned content
- metric outputs are TSV; conclusions are written separately in Markdown
