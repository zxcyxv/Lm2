## Question

Can one jointly learned encoder, lightweight complex central recurrence, and
analytic inverse decoder learn

`T(E(x_<=t)) ~= E(x_<=t+1)`

well enough that repeated self-composition follows the same model's greedy
decode--append--re-encode AR trajectory through four steps?

Every KV write is generated from the central layer's own continuous
prediction.  The recurrence receives no held-out future byte, generated byte,
token embedding, teacher model, EMA state, or distillation signal.

## Fixed model and readout

- byte vocabulary 256; width 1344; two reversible causal encoder blocks
- analytic exact-inverse decoder
- fixed regular-simplex codebook shared by input embedding and output scoring
- raw tied logits: `16 * decoded_hidden @ codebook.T`
- no independent head, output-vector normalization, radius loss, temperature
  coefficient, innovation gate, EMA, sampled branch, or token-conditioned
  update

The encoder and decoder are inverse functions.  The central layer is not
required to be injective or reversible.

## Central recurrence

- 8 heads
- complex key dimension 16 per head
- complex value dimension 31 per head
- learned unit-modulus hidden-channel and memory-row rotations
- no decay

For each known root `h`, initialize `S_0 = k(h) v(h)^dagger`.  One step:

1. rotate `h` and `S` by global learned phases;
2. read the innovation-free prior `h_prior = q(h_rot)^dagger S_rot`;
3. send only `h_prior` through the inverse decoder for next-byte CE;
4. compute `I = k(h_prior) v(h_prior)^dagger` from that same continuous
   self-prediction;
5. set `S_next = S_rot + I` and
   `h_post = h_prior + read(q(h_prior), I)`.

`h_post`, not `h_prior`, is the recurrent state and attached latent
prediction.  The current decoder never sees its own innovation.  There is no
coefficient on `I`, learned beta, interpolation, gate, or temperature.

## Objective

Train horizon one at every stride-one prefix anchor:

`L_CE = CE(raw_tied_logits(D(h_prior)), byte_(t+1))`

`L_H1 = ||h_post - h_(t+1,online)||^2 / ||h_(t+1,online)||^2`

`L = L_CE + L_H1`.

The online target remains attached so the encoder coordinate system and
central transition are jointly learned.  It appears only on the loss side.
Monitoring self-composes the central recurrence for four steps and decodes
the completed causal tape in one inverse-decoder call.
